# 성인을 위한 필수 상식 가이드 프로그램(Database)

이 리포지토리는 '성인을 위한 필수 상식 가이드 프로그램' 프로젝트의 문제 데이터 및 사용자 학습 이력을 관리하는 텍스트 기반 데이터 저장소입니다. 백엔드 및 프론트엔드 소스 코드와 분리하여 정적 데이터(문제)와 동적 데이터(오답 노트)를 독립적으로 관리하기 위해 구성되었습니다.

## 📂 파일 구조 (File Structure)

* `quiz_data.txt`: 사지선다형 퀴즈 및 카드 분류 게임용 초기 문제 더미 데이터 (읽기 전용 권장)
* `user_record.txt`: 사용자별 문제 풀이 결과 및 오답 노트 누적 데이터 (동적 파일)
* `.gitignore`: 로컬 테스트 시 변경되는 동적 데이터(`user_record.txt`)의 무의미한 커밋 충돌을 방지하기 위한 설정 파일

## 📝 데이터 구조 명세 (Data Specification)

자바 백엔드 `FileIOUtils`에서 파싱 오류가 발생하지 않도록, 모든 텍스트 데이터는 `|` (파이프) 기호를 구분자로 사용하여 한 줄씩 작성해야 합니다.

### 1. 사지선다형 퀴즈 데이터 (`quiz_data.txt`)
* **구조:** `카테고리 | 문제내용 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호(1~4)`
* **예시:** 
  ```text
  사회상식|다음 중 근로기준법상 법정 근로시간은 주당 몇 시간일까요?|40시간|45시간|52시간|60시간|1
  기초예절|직장 상사에게 이메일을 보낼 때 올바른 제목 작성법은?|안녕하세요.|[업무보고] 10월 매출 현황 보고드립니다.|제목 없음|저기요|2

### 2. 카드 분류 게임 데이터
* **구조:** `정답(O 또는 X) | 카드에 적힐 문장`
* **규칙:** 백엔드 판별 로직을 위해 첫 번째 항목은 반드시 대문자 O 또는 X로 작성합니다.
* **예시:** 
  ```text
  O|결혼식 축의금 봉투 뒷면 왼쪽 하단에 소속과 이름을 적습니다.
  X|장례식장에서 상주에게 인사할 때는 먼저 다가가 악수를 청하는 것이 예의입니다.

### 3. 오답 노트 및 학습 이력 (user_record.txt)
* **구조:** `게임유형 | 문제내용 | 내가고른답 | 실제정답`
* **예시:** 
  ```text
  퀴즈|직장 상사에게 이메일을 보낼 때 올바른 제목 작성법은?|1|2
  카드|장례식장에서 상주에게 인사할 때는 먼저 다가가 악수를 청하는 것이 예의입니다.|O|X

## 💻 팀원 환경 세팅 가이드 (How to Use)
백엔드/프론트엔드 파트 팀원들은 로컬 환경에서 개발 및 테스트를 진행할 때 다음 규칙을 따라주세요.
* 메인 애플리케이션 프로젝트(OOP-AppForAdults) 최상위 경로에 data 폴더를 생성합니다.
* 이 리포지토리의 .txt 파일들을 해당 data 폴더 안으로 다운로드하거나 복사합니다.
* 로컬에서 게임을 실행하면 user_record.txt 파일의 내용이 실시간으로 갱신됩니다.
* 주의: 로컬에서 플레이하여 갱신된 user_record.txt 파일은 개인의 테스트 결과이므로 깃허브에 커밋(Push)하지 않습니다. .gitignore에 이미 해당 파일이 등록되어 있으므로 강제로 추가(git add -f)하지 않도록 주의해 주세요.
